# 积分备份器

**一键备份，一秒回顾——无需安装 Python 环境，但请确保系统满足下方要求。**

---

## 功能速览

- 📁 每天自动将积分表按日期编号备份，防止覆盖
- 👁 备份后自动全屏打开 Excel，直接定位到 LOG 最后一行
- 🧹 自动清除文件隐藏属性，备份清晰可见
- ⏱ 可加入 Windows 定时任务，实现无人值守

---

## 使用方法

1. 下载 `积分备份器.exe`，放在任意位置。
2. 双击运行，即刻完成备份并打开 Excel 全屏查看最新记录。
3. （可选）添加到系统任务计划，每日定时自动备份。

---

## 系统要求

本 exe 基于 **Python 3.13 (64-bit)** 打包，下列环境可获得最佳体验：

- ✅ **推荐**：Windows 10 版本 1607 或更新的 64 位系统
- ⚠️ **可能兼容**：Windows 8 / 8.1 (64-bit)，部分功能可能受限
- ❌ **不支持**：32 位 Windows 及 Windows 7 等更旧系统（如有需要，可联系获取基于旧版 Python 重新打包的版本）

---

## 与“乞分君”无缝配合

日常推荐工作流：

1. 在 [乞分君](https://github.com/bgsgp/scorerlauncher) 中录入积分
2. 运行“积分备份器.exe”，立刻生成带日期的安全副本
3. 弹出的 Excel 窗口直接展示最新日志，检查更方便
